# EasyMaple

A for-fun MapleStory farming bot built to automate grinding routines. Feel free to use it, learn from it, or build on top of it.

## What it does

- Reads a routine file and automatically moves your character around a map
- Detects runes and solves them automatically
- Sends Discord notifications for important events (rune spawns, deaths, elite bosses)
- Provides a GUI to create and edit routines visually

## Getting started

Requires Python 3.10+ and [uv](https://github.com/astral-sh/uv).

```bash
uv sync
python main.py
```

Make sure MapleStory is running in windowed mode before launching.
